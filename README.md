# Лабораторная работа №3: Markdown и LaTeX

## Краткое описание
Данный проект создан в рамках выполнения лабораторной работы №3. В ходе работы я изучила синтаксис языка разметки Markdown, научилась оформлять документацию, создавать таблицы, списки и вставлять изображения. Также я освоила базовое использование формул LaTeX для оформления математических выражений прямо в Markdown-файлах.

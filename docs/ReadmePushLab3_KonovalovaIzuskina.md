# Краткое описание моего пуша
Я создала нужные папки (`docs`, `img`, `latex`), выполнила команду `git init`, чтобы Git начал отслеживать мой проект. Потом создала файл `README.md`, добавила его в отслеживание и сделала первый коммит

Дальше я зашла на сайт GitHub, создала там новый пустой репозиторий и скопировала ссылку на него. 
После этого в терминале я написала команду:
`git remote add origin <ссылка>`

Так я привязала свою локальную папку к сайту. И наконец, я отправила все свои файлы на GitHub с помощью команды:
`git push -u origin master`

В терминале появилось много текста, но в конце было написано `branch 'master' set up to track 'origin/master'`, и это значит, что мой пуш прошел успешно и все файлы теперь есть на GitHubе

> [!TIP]
> **Совет по использованию**: Для экранирования специальных символов в Markdown используйте обратный слэш `\`.

### Escape-символы
* Заголовок без форматирования: \# Это не заголовок
* Звёздочка как текст: \*Просто звёздочка\*
* Нижнее подчёркивание: \_просто_текст\_

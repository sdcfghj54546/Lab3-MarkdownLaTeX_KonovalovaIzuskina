## Блоки кода и цитаты

### Встроенный (inline) код
Команда `git status` показывает текущее состояние репозитория.

### Блок кода с указанием языка
```csharp
Console.WriteLine("Hello, Markdown!");
```
### Блок кода обычный
```
Просто какой-то текст внутри блока кода.
Он не будет подсвечиваться цветами.
```

### Цитаты

> Это обычная цитата в Markdown.
> Она может занимать несколько строк.
> Первый уровень вложенности
>> Второй уровень вложенности
